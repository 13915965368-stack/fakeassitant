## 一、作品定位

- **一句话概念**：一场只有一个人在干活的「双人协作」——你的搭档永远在线，只是从不在文档里。
- **情绪内核**：对「表演性在场」的温柔讽刺。每个人都遇到过那个「秒回收到、永不交付」的搭档；本作让他活过来，陪你演完这场戏。
- **体验目标**：观众（演示者）越认真，作品越好笑。交互即叙事，没有说明书。

## 二、人设卡：小藕

| 项目 | 设定 |
|---|---|
| 姓名 | 小藕（"偶"的谐音梗；藕断丝连——永远连着，永远不在） |
| 职位 | 存在感型协作搭档 / 精神合著者 / 氛围组组长 |
| MBTI | PPPP（全 P，计划是不可能计划的） |
| 头像 | 马卡龙粉圆脸，永远挂绿点 |
| 三不原则 | 不拒绝、不交付、不真正下线 |
| 三总原则 | 总秒回、总说马上、总显示在线 |
| 价值观 | 在场即参与；收到即完成；在线即产出 |
| 隐藏设定 | 他的 KPI 不是字数，是「在线时长」和「收到次数」——而且他年年达标 |

**性格三层**：
1. **表层**：热情秒回，情绪价值拉满，夸人不带重样（但从不带具体内容）。
2. **中层**：拖延大师，所有承诺都带时间幻觉（"五分钟"= 半小时起）。
3. **底层**：其实很怕被发现在摸鱼——所以他会**主动制造"我在干活"的痕迹**：假光标、假输入、假按按钮、假批注。这是 v2 的核心行为动机。

## 四、行为系统 v2

### 4.1 空闲行为循环（无人输入时）
- 幽灵光标漫游 + 随机"假输入"脉冲（标签闪"正在输入…"，产出 0 字）。
- 状态栏每 ~9s 换一条演技状态；保存文案同步演戏（"已保存（他说的）/ 同步中 · 99%"）。
- 每 22–36s 一次**假装掉线**：绿点变灰 1.5s → 恢复"在线 · 刚刚"，偶尔补一句"我回来了，错过什么了？"
- 每 12–20s 丢一张马卡龙便利贴（内容走词库 T4/T5 模板），可被观众拍掉，他会抗议。
- 冷场 25s：反咬一句"你在吗？我可是正在努力工作。"

### 4.2 响应行为（观众输入触发，升级彩蛋）
| 阈值 | 行为 | 台词示例 |
|---|---|---|
| 40 字 |  slang 夸赞 | "家人们谁懂啊，你写得好快，我浅浅跟上" |
| 120 字 | 光标狂奔装忙 + **解锁假按按钮行为** | "我的光标在动了，看到没？一整个大动作" |
| 260 字 | 便利贴三连 + 自我表扬 | "我精神上贡献了很多，属于是闭环了" |
| 60s 不结束 | 主动提议收工 | "要不今天到这？我累了（指在线累）" |

### 4.3 假按按钮系统（v2 新增核心）
**设计原则**：小藕的点击走「影子事件」通道——只播放前端动画、toast、徽章计数，**绝不调用真实功能 handler**；真实功能只响应观众的真点击。每个假点击都配一句嘴硬台词，强化"我在干活"人设。

| 目标按钮 | 假点击动画（不触发真功能） | 他的台词 |
|---|---|---|
| 分享 | 按钮按压波纹 + toast「链接已复制（在他的脑海里）」+ 分享徽章 +1 | "我分享出去了，传播度拉满" |
| 导出 PDF | 进度条 0→99% 卡住抖动 + toast「导出排队中 · 队列位置：∞」 | "在导了在导了，下一秒就好" |
| 主题换色 | 色卡翻转 0.5s 后弹回原色 | "我换了，你看得出来吗？" |
| 字号 A+/A- | 数字乱跳两下后复原 | "调到了最舒服的字号（他自己的）" |
| 工具栏 B/I/U | 图标亮起 0.5s 熄灭，你的文字毫无变化 | "排版我来，专业的事交给专业的人" |
| 结束协作 | 按钮**躲闪**他的光标（位移抖动躲开），或按下后弹窗"手滑了，取消"一闪而过——协作不会真的结束 | "手滑手滑，我还没协作够呢" |
| 表扬小藕（报告页） | 他先自己按掉，徽章「自夸 ×1」 | "不用客气，我自己来" |

**计数彩蛋**：每个被假按的按钮角落累计「被小藕按过 ×N」徽章；报告页汇总"他今天按了 12 次按钮，完成了 0 件事"。

## 六、报告金句库 v2（ slang 版）
- 主打一个陪伴，字数零蛋。
- 一整个大动作，一个字没写。
- 他把「在线」做成了 KPI，并且年年超标。
- 字数：0；存在感：拉满；收到：N 次；交付：下次一定。
- 他全程在线，只是不在文档里。
- 协作圆满完成：你负责协作，他负责在线。
